# Security policy

This repository contains build tooling, generated API references, credential-free templates, and optional read-only smoke-test code. It must not contain live credentials or private identifiers.

Report a suspected vulnerability privately through GitHub's security-advisory feature for `SalixiaHoldings/Cloudflare-Postman`. Do not include real Cloudflare tokens, Postman keys, account IDs, zone IDs, customer names, or production response payloads in a public issue.

Generated reference collections describe both read and write Cloudflare APIs. Users are responsible for reviewing token scope, endpoint behavior, and request payloads before sending requests. The repository's automated live smoke test is intentionally read-only.
