Comparison baseline: preserved PR #12 distribution at
`f3c6f54ecab08ce7649cd445160b4fe66ee9f99c`. Generated files are compared only
as outputs; none is fed back into construction.

The [finite construction policy](request-template-construction.md) changes
**135 live bodies**: 40 of the 56 inventoried operations and
95 other operations affected by the same generic rules. The other 16 inventoried
operations reproduce their previous body bytes successfully. Source-incomplete
membership is unchanged.

Fresh primary conversion of the changed operations finds 107 sentinel-bearing
bodies. The other 28 include null/missing required shapes, wrong primitive types,
text rows for binary arrays and the two safe but conflicting converter objects.
The old generated bodies generally already validated; that does not make their
invented fallback values permissible construction sources under the new policy.
Every changed body is individually identified below, including changes beyond
what was needed merely to make the previously saved body valid.
